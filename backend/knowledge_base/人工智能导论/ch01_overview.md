# 第一章：AI概述与发展历史

## 学习目标
- 理解人工智能的定义与核心研究目标
- 掌握AI发展的三次浪潮与关键节点
- 了解AI的主要研究方向与典型应用

---

## 1.1 什么是人工智能

人工智能（Artificial Intelligence，AI）是研究如何使计算机系统能够执行通常需要人类智能才能完成任务的科学与工程学科。

**核心研究目标：**
- **推理与问题求解**：模拟人类的逻辑推理能力
- **知识表示**：将现实世界的知识形式化地存储在计算机中
- **规划与决策**：在复杂环境中制定行动策略
- **感知**：理解图像、语音、文本等多模态输入
- **自然语言处理**：实现人机自然语言交流

**图灵测试（1950）：** 艾伦·图灵提出，若一台机器能在对话中被人类误认为是人类，则认为该机器具有智能。这一测试虽有局限，但为AI研究确立了早期目标。

## 1.2 AI的三次浪潮

### 第一次浪潮（1950s–1970s）：符号主义的兴起

- **代表技术**：逻辑推理、专家系统、搜索算法
- **核心思想**：用符号逻辑规则表示知识，通过推理引擎解决问题
- **代表成果**：LISP语言、通用问题求解器（GPS）
- **走向衰落原因**：规模扩展困难，无法处理不确定性，进入第一次"AI寒冬"

### 第二次浪潮（1980s–1990s）：专家系统时代

- **代表技术**：知识工程、专家系统（如MYCIN诊断系统）
- **核心思想**：将领域专家知识编码为规则库
- **局限性**：知识获取困难（知识工程瓶颈），维护成本极高，泛化能力差
- **1987年专家系统崩溃**，进入第二次"AI寒冬"

### 第三次浪潮（2012–至今）：深度学习革命

- **转折点**：2012年，AlexNet在ImageNet竞赛上将错误率从26%降至15.3%，引爆深度学习
- **核心驱动力**：大数据 + 强算力（GPU/TPU）+ 深度神经网络算法
- **里程碑事件：**
  | 年份 | 事件 |
  |------|------|
  | 2016 | AlphaGo击败围棋世界冠军李世石 |
  | 2017 | Transformer架构提出 |
  | 2018 | BERT预训练模型发布 |
  | 2020 | GPT-3展示大规模语言模型能力 |
  | 2022 | ChatGPT发布，AIGC元年 |
  | 2024 | 多模态大模型全面爆发 |

## 1.4 常见误区

> **误区1：AI = 机器人**
> AI是软件智能，机器人是物理载体，两者相互独立。AI可以运行在手机、服务器上，无需物理形态。

> **误区2：现在的AI能"理解"语言**
> 当前大语言模型是通过统计规律生成文本，并非真正理解语义。它们是"随机鹦鹉"还是具备某种理解能力，学术界尚有争议。

> **误区3：AI会很快超越人类所有能力（AGI迫在眉睫）**
> AGI（通用人工智能）仍是研究愿景，当前AI在特定任务上超越人类，但在通用推理、常识理解等方面与人类仍有显著差距。
