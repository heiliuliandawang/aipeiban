## 3.1 机器学习的定义与范式

**定义（Mitchell, 1997）：** 对于某类任务T，若程序通过经验E在性能度量P上得到改进，则称该程序在T上进行了机器学习。

### 三大学习范式

**监督学习（Supervised Learning）**
- 训练数据带有标签（输入→输出对）
- 目标：学习输入到输出的映射函数
- 典型任务：分类、回归
- 示例：垃圾邮件检测（标签：垃圾/正常）

**无监督学习（Unsupervised Learning）**
- 训练数据无标签，发现数据内在结构
- 典型任务：聚类、降维、密度估计
- 示例：用户行为聚类、主成分分析（PCA）

**强化学习（Reinforcement Learning）**
- 智能体通过与环境交互，根据奖励信号学习策略
- 典型应用：游戏AI（AlphaGo）、机器人控制

## 3.2 关键概念：过拟合与欠拟合

```
训练误差 vs 测试误差：

         欠拟合区         最优区       过拟合区
误差|  ______
    |        ------___/
    |                   测试误差
    |         ___-------
    |  ------           训练误差
    +----------------------------> 模型复杂度
```

**欠拟合（Underfitting）：**
- 模型太简单，训练误差和测试误差都很高
- 原因：特征不足、模型容量太小
- 解决：增加特征、用更复杂模型、减少正则化

**过拟合（Overfitting）：**
- 模型记住了训练数据的噪声，训练误差低但测试误差高
- 原因：模型太复杂、训练数据太少
- 解决方案：
  - **正则化**（L1/L2）
  - **数据增强**
  - **Dropout**（神经网络）
  - **早停（Early Stopping）**
  - **集成方法**（Bagging、Boosting）

## 3.3 偏差-方差权衡

$$\text{期望误差} = \text{偏差}^2 + \text{方差} + \text{噪声}$$

- **偏差（Bias）**：模型假设错误导致的系统性误差（欠拟合的体现）
- **方差（Variance）**：模型对训练数据扰动的敏感程度（过拟合的体现）
- **噪声**：数据本身的不可消除误差

> 降低偏差通常会增大方差，反之亦然。选择合适的模型复杂度是权衡两者的关键。

## 3.4 模型评估

### 交叉验证（Cross-Validation）

**K折交叉验证（K-Fold CV）：**
1. 将数据集随机分为K份
2. 每次用1份作为验证集，其余K-1份训练
3. 重复K次，取平均性能

```python
from sklearn.model_selection import cross_val_score
from sklearn.linear_model import LinearRegression
import numpy as np

model = LinearRegression()
scores = cross_val_score(model, X, y, cv=5, scoring='neg_mean_squared_error')
print(f"交叉验证得分: {-scores.mean():.4f} ± {scores.std():.4f}")
```

### 常用评估指标

**分类任务：**
- 准确率（Accuracy）= 正确预测数 / 总样本数
- 精确率（Precision）= TP / (TP + FP)
- 召回率（Recall）= TP / (TP + FN)
- F1分数 = 2 × Precision × Recall / (Precision + Recall)

**回归任务：**
- 均方误差（MSE）、均方根误差（RMSE）
- 平均绝对误差（MAE）
- R²决定系数

## 3.5 正则化

**L2正则化（Ridge/岭回归）：** 在损失函数中加入 λ||w||²

$$L_{ridge} = L_{原始} + \lambda \sum_j w_j^2$$

- 效果：使权重均匀缩小，不会产生稀疏解

**L1正则化（Lasso）：** 加入 λ||w||₁

$$L_{lasso} = L_{原始} + \lambda \sum_j |w_j|$$

- 效果：产生稀疏解（某些权重精确为0），自动特征选择

---

## 3.6 常见误区

> **误区：训练集准确率越高越好**
> 高训练准确率可能意味着过拟合。真正重要的是在**未见过的数据**上的泛化性能。

> **误区：数据越多越好，不需要特征工程**
> 数据量固然重要，但无关特征会引入噪声，降低模型性能。特征工程在实际项目中往往比算法选择更重要。
