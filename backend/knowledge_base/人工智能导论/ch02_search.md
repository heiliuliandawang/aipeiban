---

## 2.1 问题形式化

AI中的"问题求解"首先需要将问题形式化为**状态空间（State Space）**：

- **初始状态（Initial State）**：问题的起点
- **动作集合（Actions）**：在某状态下可执行的操作
- **转移模型（Transition Model）**：执行动作后到达的新状态
- **目标测试（Goal Test）**：判断当前状态是否为目标
- **路径代价（Path Cost）**：从起点到当前状态的代价

**经典示例 - 8数码问题：** 3×3方格，8个数字和1个空格，通过移动到达目标排列。状态数 = 9! / 2 = 181440。

---

## 2.2 无信息搜索（盲目搜索）

### 广度优先搜索（BFS）

- **策略**：先展开最浅的未展开节点（FIFO队列）
- **完备性**：✅ 若解存在，必然找到
- **最优性**：✅ 若路径代价相同（等代价），找到最优解
- **时间复杂度**：O(b^d)，b为分支因子，d为最浅目标深度
- **空间复杂度**：O(b^d)——BFS的主要缺点

### 深度优先搜索（DFS）

- **策略**：先展开最深的未展开节点（LIFO栈）
- **完备性**：❌ 可能陷入无限循环（需加访问标记）
- **最优性**：❌ 不保证最优
- **时间复杂度**：O(b^m)，m为最大深度
- **空间复杂度**：O(bm)——内存友好

### 一致代价搜索（UCS）

- **策略**：按路径代价从小到大展开（优先队列）
- **完备性**：✅
- **最优性**：✅（当所有动作代价 ≥ ε > 0 时）
- 等价于Dijkstra算法

## 2.3 启发式搜索

### 贪婪最佳优先搜索

- 仅用启发函数 h(n) 评估节点（估计到目标的代价）
- **不最优**，但通常比盲目搜索快

### A* 算法（★★★ 重点）

A* 是最重要的启发式搜索算法，评估函数：

$$f(n) = g(n) + h(n)$$

- **g(n)**：从起点到节点n的实际代价
- **h(n)**：从n到目标的启发式估计代价
- **f(n)**：总估计代价

**最优性条件：可采纳性（Admissibility）**
若 h(n) 永远不高估实际代价（h(n) ≤ h*(n)），则称h为可采纳启发函数，此时A*保证最优解。

**8数码问题的启发函数：**
- h1 = 错位数字数（可采纳）
- h2 = 曼哈顿距离之和（可采纳，且 h2 ≥ h1，更精确）

```python
import heapq

def a_star(start, goal, h):
    open_list = [(h(start), 0, start, [])]
    visited = set()
    while open_list:
        f, g, node, path = heapq.heappop(open_list)
        if node in visited:
            continue
        visited.add(node)
        path = path + [node]
        if node == goal:
            return path
        for neighbor, cost in get_neighbors(node):
            if neighbor not in visited:
                new_g = g + cost
                heapq.heappush(open_list, (new_g + h(neighbor), new_g, neighbor, path))
    return None
```

## 2.4 算法对比

| 算法 | 完备性 | 最优性 | 时间 | 空间 |
|------|--------|--------|------|------|
| BFS  | ✅ | ✅（等代价）| O(b^d) | O(b^d) |
| DFS  | ❌ | ❌ | O(b^m) | O(bm) |
| UCS  | ✅ | ✅ | O(b^(C*/ε)) | O(b^(C*/ε)) |
| A*   | ✅ | ✅（可采纳h）| 取决于h | O(b^d) |

---

## 2.5 常见误区

> **误区：A*总是最快的搜索算法**
> A*的效率高度依赖启发函数的质量。若h(n)=0（退化为UCS），效率与无信息搜索相同；若启发函数不可采纳，可能找到次优解。

> **误区：DFS不能用于实际问题**
> DFS在迷宫、深度受限的搜索问题中非常实用，且内存开销小；迭代加深DFS（IDDFS）结合了BFS的完备性与DFS的空间效率。

---

## 2.6 本章小结

- 状态空间是问题形式化的统一框架
- BFS：广度优先，完备最优，内存大
- DFS：深度优先，不完备不最优，内存小
- A*：g(n)+h(n)，可采纳启发下最优，最重要的搜索算法
